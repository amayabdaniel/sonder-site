A meeting copilot that doesn't live in the cloud.

Sonder listens to your meetings — only when you tell it to — and quietly transcribes, indexes, and answers questions while you focus on the people in the call. Native macOS app + Chrome extension. Your audio stays on your machine by default.

Install How it works

Open source · Single-user, localhost-first · Works with Meet, Zoom, Teams

How it works

  1. 1

    You start it.

    Click the menu bar icon (macOS) or the side panel button (Chrome). A red indicator stays visible the whole time audio is flowing — never hidden, never automatic.

  2. 2

    It transcribes locally or via your provider.

    Audio streams over a local WebSocket to sonder-server running on your machine. From there, it's either fully on-device (Phase 4 — coming) or routed to the STT provider you choose.

  3. 3

    It answers, with context you control.

    Final transcripts are matched against a private notes index you curate, then sent to the LLM router. You see streaming answers as cards in the side panel. Cached answers come back instantly the next time the same question shows up.

Privacy promise

  • You start it. Sonder never auto-records and never auto-joins.
  • It is visible. A red indicator is on the whole time audio flows.
  • You own the data. Transcripts, notes, and cached answers live in ~/.sonder/. Nothing leaves your machine unless you opt into a cloud provider.
  • You can leave clean. Stop the server, uninstall the apps, delete ~/.sonder/. No remote state.

Install

macOS app

Native Swift / SwiftUI. Menu bar app + main window. Captures system audio via CATapDescription.

Download .app

Requires macOS 14.4+. First run grants Screen & System Audio Recording in System Settings.

Chrome extension

MV3 side panel. Captures the active meeting tab. Talks only to http://127.0.0.1:8080 on your machine.

Get from Chrome Web Store

Or load unpacked from the source.

Local backend

Single-binary Rust server. Generates a token at ~/.sonder/token on first run. Bound to 127.0.0.1.

cargo install --git https://github.com/amayabdaniel/sonder-server

Optional: DEEPGRAM_API_KEY + CEREBRAS_API_KEY in .env for cloud STT/LLM.

What it's made of

Sonder is open source. Three repos:

  • sonder-server — Rust backend, RAG, intent filter, answer cache, /metrics.
  • sonder-clients — macOS app + Chrome MV3 extension.
  • sonder-shared — Rust types + traits.
